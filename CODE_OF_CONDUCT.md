# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, focus on accurate sources, and no harassment of any kind.

Report unacceptable behaviour through GitHub's private reporting on this repository. Reports are handled confidentially, and I respond within 72 hours.
